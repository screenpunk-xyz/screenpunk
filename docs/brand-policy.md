# Brand policy

Required style source: Codex Brand & App Guide at `Brand/Style-Guide/`
(https://screenpunk-style-guide.gsuter.chatgpt.site). Do not invent a
parallel palette, type ramp, token set, or layout system. If a token or
layout is impractical, change the guide and keep provenance.

## Settled contract (2026-09-12)

- Published tokens, palette, and layout from the guide are in use now.
- Default lockup is stacked. Horizontal remains an approved alternate.
- Offline ring and other danger/error treatment use guide `danger` tokens.
- Apple controls default to iOS 27 / style-guide studies, with older-OS-safe
  fallbacks. Deployment targets stay iOS/iPadOS 16+ and macOS 26+. Do not
  require iOS 27 to run.
- Locked identity: revision 8 bevel logomark; v1 / Modular wordmark. Never
  treat under-review logos or unselected wordmark studies as approved.
- Wordmark is custom lettering, not a UI font. Use system SF on Apple.
- GitHub cloud avatar is not the app icon.
