# Connection identity assets

Used to identify the corresponding third-party connection. These marks remain the property of their respective owners; they are not Screenpunk branding.

- Cursor: original Cursor.icns from the installed official /Applications/Cursor.app bundle.
- Claude: original electron.icns from the installed official /Applications/Claude.app bundle (CFBundleIconFile).
- Codex: original icon-codex-light.png and icon-codex-dark-color.png from the installed official /Applications/ChatGPT.app bundle; appearance-selected without recoloring.
- Home Assistant: https://www.home-assistant.io/images/favicon-192x192-full.png, fetched September 13, 2026.
- Generic / Local Models: native SF Symbols `sparkles`, no third-party logo.

Original proportions and artwork are preserved, rendered with aspect-fit in a shared 48-point icon slot. The app icons have approximately 10% transparent inset on each edge; the full-canvas Home Assistant favicon receives that same inset at presentation time. The generic sparkle tile uses the matching 80% visual footprint.
